# Pre-Flight Presentation & Diagram Audit Checklist

Verify all items before delivering the final presentation package:

- [ ] **1. Native Draw.io Sources:** Every diagram is saved as an editable `.drawio` file alongside its `.png` export.
- [ ] **2. Zero Overlap:** All boxes, swimlanes, and orthogonal connectors have clear gutters and readable labels.
- [ ] **3. Visual Decor Integrity:** All stock/decor images are royalty-free, high-resolution ($\ge 800\text{px}$), and verified via Pillow.
- [ ] **4. Aspect-Ratio Preservation:** All embedded diagrams and photos use proportional scaling (no stretched images).
- [ ] **5. Canva Compatibility:** Deck is 16:9 (`13.333 x 7.5` in), uses standard sans-serif fonts, and avoids unsupported SmartArt.
- [ ] **6. Clean Workspace:** No temporary `.tmp`, `.bak`, or scratch scripts remain in the deliverables directory.
